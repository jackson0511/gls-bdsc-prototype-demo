Luồng dữ liệu kế hoạch Catalog.rules + catState → nhắc / gợi ý. PlanTemplate (scope xe) → generate MaintenancePlan[]. Đánh giá FAIL → plan/order với source=PERIODIC_ASSESSMENT.
Luồng dữ liệu thực tế Order giữ 2 cụm VT. Gửi MH theo code + pwmsObjectId. Sync MH → purchaseMaterials (snapshot). BASE sync độc lập SoT duyệt.

API / tích hợp (hướng triển khai)

  • PWMS đọc: Product search, tồn, giá tham chiếu, serial, Object danh sách xe.
  • PWMS ghi (qua tích hợp): yêu cầu xuất / nhận phiếu BD/SC theo mã; QLX không ghi đè master Product.
  • BASE: push/pull trạng thái duyệt phiếu SC.
  • Nội bộ QLX: CRUD master kỹ thuật, template, plan, order, assessment, reminder engine.
